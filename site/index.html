为什么 · WHY

检索只会找你正在找的。
梦是给你没想找的留的门。

相似度、RAG、记忆巩固,全是目标函数的延伸——盲区的定义,就是你的目标函数照不到的地方。要看见盲区,只能靠跟你目标无关的随机。

no. 3

跨时失联

一周前读过的文献,今天又撞见一篇——它们其实共享着同一个名字,你没发觉。从来没有人替你点破这条线。

Lane B · 共享的专名 / 数字 / 低频词 → 直通点破

有用是任务态的贪心,看见是另一回事。

分界线 · NOT

四件它坚决不做的事。
做到任何一件,它就不再是梦。

不喂模型

梦话永不回流进记忆、不进训练。那不是做梦,是喂镜子——镜子里的东西,越来越像它自己。

不建议

命中"建议 / 应该 / 下一步"的 open_question,直接降为 noise——写死在代码里,不靠提示词碰运气。梦不立项。

不相似

配对永远不看像不像。相似度一插手,它就退化成又一次检索:温柔,高效,永远绕开你的盲区。

不保证

95% 的夜晚是废话,如实写在文档里。以命中率为由调整随机性,是被明文禁止的改动。

分辨真假做梦只看一件事:梦话喂给了谁。 喂给模型的,是在训练自己;喂给人的,才是在看世界。

实验 · THE BET

仪器很简陋,
但假说是清楚的。

唯一做过 REM 的同行,在事实回忆基准上测出"无可测收益"——作者自己承认的。这不能怪 REM:量桌子的尺子,量不出一段音乐。

所以我们的尺子换成了人。意外不意外,机器打分;有没有用,只算你某个早上敲下 confirm 那一下。缺一,信号不成立。

serendipity = 意外(surprise) ∩ 有用(人工确认)
RecSys 领域对 serendipity 的标准定义,二者缺一不可
误杀回收 0 → ≥1/月 · 趋势命中 登记后 14 天对账 · 跨时确认 0 → ≥1
梦产率 长期期望值低,如实展示 · 存在感指标:两周后,你是否开始期待晨报

给 Agent 用 · SKILL

不做常驻服务。
一个 Skill,四个命令。

仓库自带 skills/dream/SKILL.md:Hermes、ZCode 或任何会读 SKILL.md 的宿主,复制过去就接入。agent 的四个动作:

# 1 · 丢废料:会话里的废弃方案、失败尝试、犹豫
$ python -m dreamlayer drop "废弃方案:把 waker 挂进 cron" --tag discarded --origin zcode
# 2 · 做一夜梦(夜里触发,或手动)
$ python -m dreamlayer run --once
# 3 · 读晨报:data/morning/<今天>.md,把观察与问题转述给人
# 4 · 陪人过审:逐条确认有效回流(或 --batch 批量)
$ python -m dreamlayer review
