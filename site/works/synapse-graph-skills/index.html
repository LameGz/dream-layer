Synapse
Graph Skills

编码代理的图式工程记忆——把"记得这次改了什么"从聊天记录里搬进文件图谱:meta/*.md 节点 + 自动生成的 MEMORY_MAP,Markdown 是唯一真相,SQLite 只是可丢弃的缓存。

解决什么

独立全栈开发者的项目记忆住在聊天历史里:跨会话蒸发、跨工具断裂、模块一多就退化成暴力重读文件。Synapse 把它变成无缝的双向流——你只管写代码。

两条无缝

  • 无缝写入(SessionEnd) — 会话结束时,钩子从 git diff 与对话信号里提取值得记的变更:高置信(≥70%)静默落库,低置信进 Memory Inbox 等你审。
  • 无缝读出(UserPromptSubmit) — 你提问时,钩子把相关记忆节点的摘要注入上下文,中文提问也认(内置跨语言主题别名)。

Eval 实测

文件读取12 → 6
无关文件5 → 0
断言通过75% → 100%

跨宿主可插拔

CLAUDE CODEhooks 全生命周期接入,完全无缝
CODEX / GEMINI CLI / CURSOR 等托管 AGENTS.md 段,半无缝
任意宿主agent-instructions.md,手动接线

纪律与零依赖

检索讲规矩:先 MAP、再目标节点、后有界 BFS(深度 ≤2、宽度 ≤5)——模块再多,上下文也是平的。零依赖:bash 4+ 与 Python 3.8 标准库,无 pip、无 npm、无外部 API、无向量数据库。
