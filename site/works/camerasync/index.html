作品 04 · PYTHON · 小工具

CameraSync

把数码相机里的照片导入电脑,不用再一层层翻文件夹。插上相机 → 扫描 → 选日期 → 下载,三步搞定。

为什么要用它

Windows 资源管理器能读相机,但每次都要从 可移动存储/DCIM/100NZ_30 一路点进去;想按拍摄日期挑照片、批量下载、换保存路径,都不顺手。这个小工具只做一件事:跳过这些重复操作。

三步

01 · 扫描自动发现 USB 连接的相机(MTP/PTP 模式)
02 · 筛选按拍摄日期自动分组,点选即勾,再点取消
03 · 下载自选路径,按 YYYY-MM-DD 子目录归类,重名自动处理

功能清单

  • 一键扫描 — 自动发现 USB 连接的相机;
  • 按日期筛选 — 自动按拍摄日期分组;
  • 单击即选 — 不用 Ctrl,点一下选中,再点取消;
  • 自选路径 — 默认按日期子目录归类;
  • 批量下载 — 全选 → 下载,重名文件自动处理不卡壳。

支持设备

Nikon · Canon · Sony · Fujifilm · Panasonic · Olympus · Pentax 等 MTP/PTP 协议相机。
