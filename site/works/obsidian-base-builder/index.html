Obsidian
Base Builder

从零搭建 Obsidian 个人知识库的实战手册:PARA 目录、中文命名、5 份 Templater 模板、5 个社区插件、Git 自动备份,以及 Claude 剪藏工作流——每一步都带踩坑记录。

打开 vault 的每天是这样

自动弹出今天的 Daily Note,日期已填好;左侧日历点日期即跳转;灵感丢进收件箱,周日 15 分钟归档;好文章把链接发给 Claude,自动抓取归类;全部内容每 30 分钟备份到 GitHub 私有仓库。

PARA 目录

E:\Vault\ ├── 00_收件箱/ ← 临时剪藏落点 ├── 01_项目/ ← 有截止日期的项目 ├── 02_领域/ ← 长期职责与学科 ├── 03_资源/ ← 主题资源与读书笔记 ├── 04_归档/ ← 已完成或不再活跃 ├── 05_日志/ 90_模板/ 99_附件/

手册覆盖

  • Templater 模板 ×5 — Daily / Meeting / Project / BookNote / Clipping,开箱即用;
  • 社区插件 ×5 — 日历、剪藏、归档自动化,选型理由都写了;
  • Git 备份 — 30 分钟一拍,私有仓库,含 .gitignore 纪律;
  • Claude 剪藏工作流 — 链接进结构化笔记的完整链路;
  • 踩坑记录 — 命名、同步冲突、插件互相打架,踩过的都记了。
